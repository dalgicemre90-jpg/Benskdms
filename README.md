# SkyDungeonMobPersistFix

Bu plugin, SkyDungeon mob/boss noktalarını güvenilir şekilde kaydeder ve server restart sonrası geri yükler.

## Build

```bash
mvn clean package
```

Oluşturulan JAR dosyası `target/` klasöründe bulunacaktır.

## Gereksinimler

- Java 21+
- Maven 3.6+
- Paper 1.21.4+
- SkyDungeon Plugin

## Kurulum

Oluşturulan JAR dosyasını server'ın `plugins/` klasörüne koyun ve restart edin.
